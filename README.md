# Tomas Karounas

Personal portfolio published with GitHub Pages at https://tkarounas.github.io/.

This is a static website. `index.html`, the JavaScript and CSS files, and `assets/` are served directly. No installation or build step is required. `.nojekyll` keeps GitHub Pages from applying a Jekyll build.

GitHub Pages publishing source: branch `main`, folder `/`.

The character animations are local video clips, with transparent animated WebP fallbacks. The site works independently of this chat or the computer used to edit it.
